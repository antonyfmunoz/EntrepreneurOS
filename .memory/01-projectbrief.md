# Project Brief

Project Name:
EntrepreneurOS

Purpose:
EntrepreneurOS is a SaaS operating system for founders to run their businesses using AI agents.

Core Capabilities:

- AI agents that perform business tasks
- Task delegation system
- company management
- agent orchestration
- workflow automation

Target Users:
Entrepreneurs and creators managing businesses with AI assistants.

Core System Flow:

auth
→ onboarding
→ create company
→ dashboard
→ agents
→ tasks

Primary Features:

agents
tasks
company setup
ai workflows
notifications

Constraints:

web-first SaaS
React frontend
Node backend
Postgres database
Neon hosting
