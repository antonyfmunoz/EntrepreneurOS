    **Write tests FIRST.** Both functions are pure — no AI calls, fully deterministic, highly testable.

    Create `lib/spec-parser/chunk-spec.ts`:

    **Function 1: chunkRawText (addresses HIGH review concern: chunking sequence)**

    This function enables the skill to pre-chunk raw text BEFORE the first AI call, so that oversized raw input doesn't fail during restructuring.

    1. Export `function chunkRawText(rawText: string, maxChunkSize: number = 15000): string[]` that:
       - If rawText.length <= maxChunkSize, return `[rawText]` (no chunking needed)
       - Split text at markdown heading boundaries (lines starting with `#` or `##`)
       - Group consecutive sections until adding another would exceed maxChunkSize
       - If a single section exceeds maxChunkSize, split it at paragraph boundaries (double newlines)
       - Return array of text chunks, each under maxChunkSize
       - Preserve all content — no text lost across chunks

    **Function 2: chunkSpecByDomain (post-parse chunking for 26+ pages)**

    1. Import `PageSpecFull` type from `@shared/spec-schema.js`
    2. Define domain detection rules as a constant map:
       ```typescript
       const DOMAIN_PATTERNS: Record<string, RegExp[]> = {
         "auth-onboarding": [/\/(auth|login|signup|register|verify|forgot|reset)/i],
         "admin-settings": [/\/(admin|settings|preferences|config|profile)/i],
         "core-features": [/./],  // catch-all for everything else
       };
       ```
    3. Export `function chunkSpecByDomain(pages: PageSpecFull[], chunkSize: number = 15): PageSpecFull[][]` that:
       - If pages.length <= 25, return `[pages]` (D-24: no chunking below 26)
       - Group pages by domain using route pattern matching
       - If any group exceeds `chunkSize`, split it further by priority order
       - Ensure no chunk exceeds 20 pages (hard cap for AI context budget)
       - Return array of chunks, each chunk is PageSpecFull[]

    **How the skill uses these (documented for executor context):**
    - For raw text input: skill calls `chunkRawText(rawInput)` FIRST. If it returns multiple chunks, call `restructureSpec` on each chunk, then merge the results.
    - For parsed pages needing re-processing: skill calls `chunkSpecByDomain(pages)` to split, then processes each chunk, then runs deduplicateComponents across all chunks.
