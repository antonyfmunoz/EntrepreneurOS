<objective>
Implement the HTML-to-shadcn Claude AI translation module and the page file writer that creates properly structured React page files in the existing codebase.

Purpose: Translation (INTG-02) is the core intelligence of Phase 4 — it takes raw Stitch HTML and converts it to TypeScript React using the project's existing shadcn/ui library. The page writer (INTG-03) handles the mechanical step of writing the translated output as a properly structured page file. Together they form the middle of the per-page pipeline: audit -> **translate -> write** -> wire route -> add nav -> commit.

Output: `lib/code-integrator/html-to-shadcn.ts` (AI translation), `lib/code-integrator/page-writer.ts` (file writer), and unit tests for both.

    ```typescript
    import { writeFile, access } from "fs/promises";
    import { join } from "path";
    import { exec } from "child_process";
    import { promisify } from "util";

    const execAsync = promisify(exec);

    // Convert PascalCase or camelCase to kebab-case
    function toKebabCase(name: string): string {
      return name
        .replace(/([A-Z])/g, '-$1')
        .toLowerCase()
        .replace(/^-/, '')
        .replace(/--+/g, '-');
    }
    ```
