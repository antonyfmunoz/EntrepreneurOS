# Plan 04-05 — Codex Code Review Integration

## Objective

Run a Codex-style code review on every translated TSX file before commit, plus best-effort `code-review` and `simplify` skill passes and a `verification-before-completion` checklist before git commit.

## Why

Phase 4's HTML-to-shadcn translation already strips data-fetching code, but it has no second-pair-of-eyes review for shadcn misuse, type issues, or React anti-patterns. The user spec asked for plan `04-04`, but `04-04-PLAN.md` already exists as a gap-closure plan for the Phase 4 push/PR step. This work lands as `04-05` instead.

## What

1. **Library**:
   - `lib/code-integrator/codex-review.ts` — `reviewWithCodex`, `parseCodexReview`. CRITICAL/WARNING/INFO bucket parser with line-by-line state machine (avoids JS regex `\Z` footgun).
   - `lib/code-integrator/skill-reviews.ts` — `queryCodeReviewSkill`, `querySimplifySkill`, `queryVerificationSkill`. All Anthropic API calls with skill-aware prompts. Fail-open.
2. **SKILL.md**: Insert Step 3b-1 (Codex review, after translation), Step 3b-2 (code-review + simplify, fire-and-forget), Step 3f-1 (verification, before commit).
3. **Tests**: 7 vitest cases covering parser severity buckets, fail-open behaviour, malformed responses.

## Notes

- `codex-cli-runtime` is a Claude Code Skill, not a callable Node API. The library invokes Claude with a skill-aware prompt — the most honest runtime approximation. SKILL.md documents this explicitly.
- Critical findings present three options (fix-and-continue / retry / skip). Decision is orchestrator-level, not library-level.
