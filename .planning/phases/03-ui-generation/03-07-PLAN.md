# Plan 03-07 — Skill Enrichment Layer

## Objective

Inject session-level production-design guidance into every Stitch prompt by querying the `frontend-design` and `ui-ux-pro-max` skills via the Anthropic API once per pipeline run, and persist `componentDirection` across token revisions so design intent survives page-to-page generation.

## Why

Investigation showed three concrete gaps in Phase 3:

1. `componentDirection` returned by the design system seeder is consumed once on Page 1, then lost — every later page regenerates with no memory of intended aesthetic.
2. The component-discovery layer was filtered to "complex" components only, so Button/Input/Card never benefited from shadcn/MagicUI references.
3. Stitch prompts had no production-grade design context beyond raw token constraints — outputs drifted toward generic AI aesthetics.

## What

1. **Schema**: Add `dm_tokens.component_direction TEXT` (migration 20260407).
2. **Library**: Create `lib/ui-generator/skill-enrichment.ts` exporting `queryFrontendDesignSkill`, `queryUXProSkill`, `enrichOnce`, `extractIndustry`. All queries are Anthropic API calls with skill-aware prompts. Fail-open everywhere.
3. **Types**: Add `SkillEnrichment` to `lib/ui-generator/types.ts`.
4. **Prompt builder**: Add 6th `enrichment?` parameter to `buildStitchPrompt` and inject design-guidance / palette / fonts at the top of the prompt before per-page constraints.
5. **Component discovery**: Remove `COMPLEX_COMPONENT_PATTERNS` filter — query registries for every component.
6. **Seeder**: `seedToTokens` carries `componentDirection` into the partial token row.
7. **SKILL.md**: Add Step 1.5 (skill enrichment, runs once per pipeline) and update Step 0.5 + Step 4e to persist `componentDirection` across revisions.
8. **Tests**: 10 vitest cases mocking `@anthropic-ai/sdk`.

## Verification

- `npm run db:migrate` applies migration idempotently
- `npx vitest run tests/unit/ui-generator/skill-enrichment` → 10/10 pass
- `grep -r "queryFrontendDesignSkill" lib/` returns hits in skill-enrichment.ts
- Page 2+ run shows "✓ Frontend design guidance received" once at start
- New `dm_tokens` row carries forward `component_direction` from prior version
