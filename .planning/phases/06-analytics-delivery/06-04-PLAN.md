    **CLI commands per target:**
    ```typescript
    const CLI_COMMANDS: Record<HostingTarget, string> = {
      railway: "railway up",
      render: "curl -X POST $RENDER_DEPLOY_HOOK_URL",
      fly: "flyctl deploy --remote-only",
      custom: "",  // user provides custom script
    };

    const CLI_INSTALL_INSTRUCTIONS: Record<HostingTarget, string> = {
      railway: "Install Railway CLI: npm install -g @railway/cli && railway login",
      render: "Render uses deploy hooks — no CLI install required. Set RENDER_DEPLOY_HOOK_URL in .env",
      fly: "Install Fly CLI: curl -L https://fly.io/install.sh | sh && fly auth login",
      custom: "No CLI required for custom deployment",
    };

    const CLI_BINARIES: Record<HostingTarget, string> = {
      railway: "railway",
      render: "curl",   // curl is always available
      fly: "flyctl",
      custom: "",       // no check needed
    };
    ```

    **checkCLIAvailable(target: HostingTarget, execFn?: typeof execSync): boolean** — For "custom" target, always returns true. Otherwise, runs `execFn("which ${CLI_BINARIES[target]}", { stdio: "ignore" })` in a try/catch. Returns true if no throw, false if throws. `execFn` defaults to `execSync` for test injection.

    **runDeploy(target: HostingTarget, confirmed: boolean, options?: { customScript?: string; cwd?: string; env?: Record<string, string> }, execFn?: typeof execSync): DeployRunnerResult** — Per D-14/D-17:
    1. If `!confirmed`: return `{ target, confirmed: false, executed: false }`
    2. If target !== "custom" and !checkCLIAvailable(target, execFn): return `{ target, confirmed: true, executed: false, error: CLI_INSTALL_INSTRUCTIONS[target] }`
    3. Determine command: `target === "custom" ? (options?.customScript ?? "echo 'No custom script provided'") : CLI_COMMANDS[target]`
    4. Try `execFn(command, { cwd: options?.cwd, env: { ...process.env, ...options?.env }, stdio: "pipe", encoding: "utf-8" as any })`
    5. On success: return `{ target, confirmed: true, executed: true, output: stdout }`
    6. On error: return `{ target, confirmed: true, executed: false, error: (error as Error).message }`

    **Test file** — Mock execSync via vi.fn() passed as execFn parameter. Verify correct CLI command strings, error handling, and confirmation gate behavior.
