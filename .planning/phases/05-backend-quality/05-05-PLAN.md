# Plan 05-05 — Codex Adversarial Security Review + TDD Skill

## Objective

Before running migrations, perform an adversarial security review on the generated routes/schema/storage, surfacing SQL-injection / auth-bypass / race-condition / input-validation vulnerabilities. Also expose a `superpowers:test-driven-development` skill wrapper that emits draft test scaffolding before implementation.

## Why

Phase 5 currently generates Express routes + Drizzle schema + storage functions, runs migrations, and runs an existing test-fix loop. There's no adversarial pass that thinks like an attacker — exactly the kind of review where human reviewers add the most value, and exactly the kind where Codex-style critique is well-suited.

## What

1. **Library**:
   - `lib/backend-wirer/codex-adversarial.ts` — `adversarialReview`, `parseAdversarialReview`, types `AdversarialReviewResult` / `AdversarialFinding`. CRITICAL / HIGH / MEDIUM / LOW severity buckets, parser uses pipe-separated `<category> | <description> | <mitigation>`.
   - `lib/backend-wirer/tdd-skill.ts` — `queryTDDSkill(spec)`. Generates draft integration tests via Anthropic API with TDD skill prompt. Fail-open: returns `""` on error.
2. **SKILL.md**: Insert Step 2.5 (TDD skill draft, after brownfield audit) and Step 5.5 (adversarial review, after wiring plan assembly, before migration). Critical/high findings present 3 options (fix / accept-and-continue / abort).
3. **Tests**: 6 vitest cases — parser bucketing, unknown-category normalisation, fail-open, end-to-end with mocked client.
