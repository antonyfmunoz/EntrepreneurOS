  <action>
    Create lib/backend-wirer/wiring-applier.ts:

    **`applyWiringPlan(projectRoot: string, plan: BackendWiringPlan, inventory: BackendBrownfieldInventory): Promise<WiringApplyResult>`**

    Per D-03: Before writing, check `plan.validationResult.valid`. If false, throw with collisions/gaps details. This prevents partial writes that leave the codebase in a broken state.

    Implementation:

    1. **Validate** — if `!plan.validationResult.valid`, throw error listing all collisions and gaps

    2. **Apply schema blocks** (per D-15 — must come first since routes/storage may reference new tables):
       - Read `shared/schema.ts`
       - For each SchemaCodeBlock in `plan.newSchemaBlocks`:
         - Append `\n\n` + `block.drizzleCode` + `\n\n` + `block.zodInsertCode` + `\n\n` + `block.typeExportCode` at `inventory.schemaInsertionOffset` (end of file)
       - Write back to `shared/schema.ts`

    3. **Apply storage functions** (per D-07 — must come before routes since routes call storage):
       - Read `server/storage.ts`
       - For each StorageCodeBlock in `plan.newStorageFunctions`:
         - Insert `\n\n  ` + `block.code` + `\n` at `inventory.storageInsertionOffset` (before closing brace of class)
       - Write back to `server/storage.ts`

    4. **Apply route blocks** (per D-06, D-08):
       - Read `server/routes.ts`
       - If `inventory.routesInsertionOffset === -1`, throw error: "Cannot find createServer(app) anchor in routes.ts — routes insertion aborted"
       - For each RouteCodeBlock in `plan.newRoutes`:
         - If `block.zodSchemaCode`, prepend it before the route handler
         - Insert `\n\n` + (zodSchemaCode if present) + `\n` + `block.code` + `\n` at `inventory.routesInsertionOffset`
       - Write back to `server/routes.ts`

    5. **Apply hook injections** (per D-02):
       - For each HookInjection in `plan.hookInjections`:
         - Read `injection.pageFilePath`
         - Add `injection.hookImport` to the imports section (after existing @tanstack/react-query import or after last import line)
         - Add `injection.hookCode` inside the component function body (after the opening `{` of the function component)
         - Write back to `injection.pageFilePath`

    6. **Return result:**
       ```typescript
       interface WiringApplyResult {
         filesModified: string[];
         routesAdded: number;
         schemaTablesAdded: number;
         storageFunctionsAdded: number;
         hooksInjected: number;
       }
       ```

    **Key implementation details:**
    - When inserting at offsets, work BACKWARDS (highest offset first) so earlier offsets remain valid
    - Use `readFile` / `writeFile` from `fs/promises`
    - Each file is read once, all insertions for that file applied, then written once (no multiple read-write cycles per file)
    - String splice: `content.slice(0, offset) + newCode + content.slice(offset)`

    Create tests/unit/backend-wirer/wiring-applier.test.ts:
    - Mock `fs/promises` readFile and writeFile
    - Test: throws when validationResult.valid is false
    - Test: inserts route code before createServer anchor at correct offset
    - Test: appends schema code at end of schema content
    - Test: inserts storage function before closing brace at correct offset
    - Test: adds hook import and hook code to page file content
    - Test: throws when routesInsertionOffset is -1
    - Test: returns correct WiringApplyResult with file counts
